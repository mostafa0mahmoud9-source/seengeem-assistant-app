# مساعد سين جيم — الكمبيوتر وأندرويد

الواجهة مرتبطة بخادم المنصة الحالي على https://seengeem-eg.com/seengeem-assistant/ وتستخدم صلاحيات وحسابات ووردبريس نفسها. لا توجد مفاتيح واتساب أو بيانات طلاب في هذا المستودع.

## التنزيل

الملفات المعتمدة تُنشر في GitHub Releases بعد نجاح البناء. نسخة ويندوز Setup بصيغة EXE، ونسخة أندرويد APK موقعة. لا تعتبر ملفات المصدر ZIP نسخة قابلة للتثبيت.

## التحديث

- ويندوز يفحص GitHub Releases بعد فتحه، ثم كل ست ساعات. ينزّل التحديث تلقائيًا ويطبّقه عند الخروج الطبيعي، بدون نافذة إشعارات.
- أندرويد يفحص عند الفتح والعودة للتطبيق، بفاصل لا يقل عن نصف ساعة. يتحقق من SHA-256 واسم الحزمة ورقم الإصدار ومطابقة توقيع APK قبل عرض زر التثبيت. موافقة Android على التثبيت لازمة.
- واجهة المتابعة تُقرأ من المنصة مباشرة. التطبيق يحتاج الإنترنت؛ لا يعرض نسخة محلية من درجات الطلاب باعتبارها بيانات حديثة. العرض الحالي على خادم المنصة يتحدث كل 20 ثانية، ومحرك الرسائل له جدولة مستقلة على السيرفر.
- استمرار التحديثات يتطلب بقاء معرّف التطبيق ومفتاح توقيع أندرويد كما هما. لا ترفع المفتاح إلى الملفات العامة.

## البناء والنشر

GitHub Actions يبني ويندوز وأندرويد عند تحديث main. لنسخة جديدة ارفع رقم version في package.json ثم ادفع التغيير. ترابط الإصدار يمنع الرجوع لإصدارات أقدم داخل أندرويد.

إعدادات توقيع أندرويد في Repository Secrets:

- ANDROID_KEYSTORE_BASE64 — ملف التوقيع الخاص بصيغة Base64.
- ANDROID_STORE_PASSWORD — كلمة مرور الملف.
- ANDROID_KEY_PASSWORD — كلمة مرور المفتاح، والاسم الثابت seengeem.

عند غياب التوقيع، يبنى APK غير موقع كملف فني لاختبار البناء فقط، ولا ينشر كبرنامج للمستخدمين. لا يدعي المشروع اكتمال نسخة APK موقعة إلى أن تظهر في إصدار GitHub.

```sh
npm ci
npm test
npm run dist:win
```

أندرويد يحتاج JDK 17 وAndroid SDK 35 وGradle 8.11.1. التطبيق يمنع HTTP وشهادات TLS غير الصالحة ووصول JavaScript إلى واجهات الجهاز. لا يطلب صلاحيات كاميرا أو ميكروفون أو إشعارات.

التحديث الآلي يخضع لنجاح GitHub Actions وتوفر الخدمة والصلاحيات. رفع مصدر الكود وحده لا يثبت بناء ونشر EXE وAPK أو نجاح تجربة تحديث على جهاز فعلي.
